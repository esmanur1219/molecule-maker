# Molecule Maker

Java Swing ve Graphics2D ile geliştirilmiş, atom ve bağlardan molekül oluşturulabilen bir masaüstü uygulaması.

## Özellikler

- Atom (daire) ve bağ (çizgi) nesneleri tıklayarak oluşturulur
- Nesneler sürükle-bırak ile taşınır, çalışma alanının dışına (sağ tarafa) bırakılarak silinir
- İlk 20 elementi içeren bir element paneli bulunur; seçilen element sembolü atoma bırakılarak atomun elementi belirlenir
- Oluşturulan yapının atom türleri, bağ sayısı ve şekil birleşimi kontrol edilir (örneğin su molekülü)

## Kullanılan teknolojiler

Java, Java Swing, Graphics2D

## Nasıl çalıştırılır

`Molecule_Maker` klasörünü bir Java IDE'sinde (IntelliJ IDEA, Eclipse vb.) açıp ana sınıfı çalıştırın.

## Bilinen sınırlamalar

Molekül doğrulama kısmı geliştirilmeye açıktır.

Üniversite dersi kapsamında geliştirilmiştir.
